# Third Eye

An offline-first OSINT toolkit PWA: a tool launcher, search and dork builders, a username checker, cases, and a data-broker removal tracker. Everything stays on your device. There are no accounts, analytics or external scripts.

**Open:** https://trevorlay.github.io/third-eye/ (on Android Chrome, use ⋮ → Install app)

Only for lawful purposes, such as auditing your own exposure or protecting family. Version 1.0.0.
